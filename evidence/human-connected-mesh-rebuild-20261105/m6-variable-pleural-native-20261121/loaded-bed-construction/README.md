The largest compression was 4.647 mm and the largest fraction of a section's stock thickness was 0.376. A positive separation carries zero force. Each pressure is passed as an initial guess to the existing Metal contact owner. The initializer applies no extra force during motion.

## Reproduction

Build the constitutive owner with its existing build_pelvic_coupling.py, the matching heart build, the motion-registry anatomical assets, native owner source, and an empty destination. The builder applies its bed-construction source change when composing the native binary. The exact compiler commands, shader and binary identities are retained with each trial. Use prepare_loaded_initialization.py with the base configuration directory, registration directory, completed donor run and a new output directory. Pass its config.json into run_cortical_trial.sh with those same assets, the new native binary, a new run directory, the Python interpreter, the requested number of physical steps and the enabled flag set to 1. The preparation verifies the donor's native skeleton, registration and qualifying material endpoint, and pins its exact source posture and field hashes.
