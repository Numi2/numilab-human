# Remove disconnected source fragments with exact ancestry

face identities match disconnected regions of the original source and
together occupy about 2.03e-12 m³ per side. They carry no compiled muscle
attachments or state. Check the effect of omitting just these source
fragments, retaining their coordinate-identical ancestry as a removal
receipt. Compare both previous collapse distances on the same input.
