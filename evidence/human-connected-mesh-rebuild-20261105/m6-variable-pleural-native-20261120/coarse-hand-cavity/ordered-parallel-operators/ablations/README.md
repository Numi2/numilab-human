# Scope of the parallel cavity operator gain

These are eight accepted roots at the same 15.625 µs step from the
byte-verified reference pack on SSH Numi's Apple M6. Each paired run
retains the same materials, tissue, ligament and bed contact,
variable pleural forcing, and acceptance thresholds. The native
body clock excludes preparation and viewer presentation.

| Path | Body time | Change versus 19.900 s control |
| --- | ---: | ---: |
| SIMD gather | 19.826 s | −0.37% |
| SIMD cached node blocks | 19.677 s | −1.12% |
| Cooperative compensated cavity operator | 16.481 s | −17.18% |
| Tiled mixed certificate | 19.742 s | −0.79% |
| Owner-incidence certificate | 19.679 s | −1.11% |
| Selected parallel operators with owner-incidence certificate | 15.936 s | −19.92% |

Every trace and emitted initial shell file matches the control, and
all 91 sampled regional force and strain comparisons pass. These
are individual measurements. The certified 64-root launch keeps
the three parallel operators selected in e183e17. The eight-root
tiled certificate results do not justify a default change.

A follow-up experiment caches compensated face position words,
cross products and signed volumes inside a Newton linearization.
Every cavity JVP still computes directional terms and sums the
same ordered words. Direct operator checks and fresh residual and
physical certificates do not read this cache. The fixture compared
serial, cooperative recompute and cooperative cached JVPs across
36 cases, including two environments, several direction fields,
invalid geometry and completed/failed environments. Valid outputs
and status comparisons were bitwise. The native rebuilt cache-off
control used 16.226 s of body time and the cache-on run used 16.178 s.
Their coupled traces and 91 regional comparisons match. This 0.29%
one-pair difference is insufficient to qualify the extra code and
storage. The experimental patches are retained here. The selected
runtime and launch do not use this cache.

The first cache-on attempt encountered ENOSPC during setup. The
completed repeat followed byte-preserving compression of the closed
control logs. Timing includes no profiler instrumentation. Fixture
commands, build overlays, binary and input pins, and their results
identify the experiment. These tests exercise a short release and
do not establish body–bed contact balance, a complete breath, or
crossing clearance through motion.
