# Newton terminal scheduling on SSH Numi

This paired replay tested whether skipping latched Newton work could retain
full-budget force and strain results. Both runs used the same Apple M6,
compiled app, dynamically loaded Matter library, Metal bundle and native
variable-pressure scene. The established GPU certificate and coupled
accept/reject path remained in force.

| 90-root native headless replay | Body time | Launch to exit |
| --- | ---: | ---: |
| Full sequence | 69.329 s | 84.491 s |
| Staged sequence | 39.885 s | 54.477 s |

Both runs accepted 1.40625 ms. Staging reduced body time by 42.47% and reached
0.00003526×. The GPU rejected the unlatched two-iteration trial. The complete
accepted state compared byte-identically on rollback before retry. Pleural
pressure ranged from −490.332520 to −490.332489 Pa, and all 34 registered
ligament rows passed the terminal audit. There was no root assistance.

The staged candidate failed 96 force and 221 strain comparisons at 1%. The
first printed coupled difference is at accepted step three. Connectivity and
nodal masses agree exactly. The prior full control and the new full control
have identical coupled traces and captured force/strain results. The new
staged trace and endpoint comparison match the previous staged trial byte
for byte. The published native launch keeps the full solver.

The build used the model's cooked cap of 16 as the terminal schedule.
The reference launch applies a runtime override to 24. The GPU therefore
records terminal iteration 15 in the staged run and 23 in the full run.
The selected pair measures the former and leaves the intended effective-cap
comparison open. The new guard checks the original convergence latch before
the attempted jump and preserves the physical certificate afterward.

This replay starts in release. Supported equilibrium, loaded shoulder
endurance, zero crossings over 16 seconds, and full-scene throughput at
0.1× remain unqualified. The [previous native evidence](../posterior-load-path/README.md)
contains separate mass and geometry results for the full-resolution reference
