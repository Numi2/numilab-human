# Posterior load transfer in the native skin and fat shell

Two matched Apple M6 runs use the fixed Matter bed, variable pleural pressure,
and the existing coupled body and controller. Both accepted 128 roots of
15.625 µs. The tied skin–fat interface, outer surface reference, shoulder
attachment sites and surrounding tissue bindings are unchanged. The candidate
changes the deep fat geometry and conserves its typed source masses.

## Registered interfaces

The 14 native elastic deep-fat attachments are all on the head and feet.
They transfer 0.01451 N upward to the skeleton in the control endpoint.
The separate unilateral tissue and bone contacts remain active. The direct
attachment resultant does not include those interactions.

reference, and separate pelvic bones. It excludes blocked rays and starting

have a median gap reduction of 2.205 mm over the selected routes. Within
2 mm of vertical closure, route count rises from four to fourteen and
projected area from 0.316 to 0.847 cm². This is a geometric capacity test.

## Build and replay

The first build failed before any accepted root. The header had used the
already-fitted surface as the raw source of its geometry guards.
`rebase_authoring_header.py` restores those sites from the exact installed
header. Both the reconstructed output and the independent source overlap
have zero measured coordinate error. This keeps the original geometry
guards and constitutive parameters. `build_engagement.py` rebuilds the
same native source with the restored reference and corresponding mass
ledger. Run `run_engagement.sh native-engagement-build-02` with the pinned
assets and build on SSH Numi. The launch and build receipts record the
source, program and dependency hashes. The compact trace and endpoint
comparison belong to the same run. The raw evidence and the replay pack
were independently downloaded from the private GitHub release and
verified byte-for-byte.

Boundary splits in the bilateral gluteal volume experiments introduced
negative Float32 cells and additional shape failures. The results remain
in the conforming-remesh screen. Those meshes and the current engagement
fit are outside the default installed scene.
