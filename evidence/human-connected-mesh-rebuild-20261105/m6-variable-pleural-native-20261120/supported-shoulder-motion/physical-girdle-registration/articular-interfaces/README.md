# Supported sternoclavicular reference repair on Apple M6

The emitted bilateral clavicle repair clears the clavicle–manubrium crossings. Its NHTENDON3 companion preserves every native tendon endpoint law. The complete native executable rejects two superior glenohumeral ligament spans before the first physical step.

## Why the repair is local

In the original BodyParts3D common frame, the right and left clavicles already intersect the manubrium in 97 and 103 triangle pairs. They also intersect the finite-thickness source skin in 38 and 31 pairs. Both scapulae clear that source skin. The audit used 185 available registered bony members. Winding at one point of a finite-thickness organ does not determine exterior containment.

Numi's full-volume reference logged a fixed horizontal bed at zero height. The four-bone registration in the parent evidence put the right scapula 52.72 mm below the bed and the left 44.66 mm below it. A closed skin enclosing those points cannot clear that bed. The original registered scapulae clear it by 42.38 and 43.07 mm at the same pose. The corresponding MyoSim source meshes, placed on the same native body frames, separately extend 5.56 and 4.91 mm below the plane. All three captured skin/fat boundaries coincide with their physical-volume nodes in the emitted coordinates.

One fit constrained by frozen skin and fat displaced both glenohumeral correspondences by about 62 mm. A rotation search maintaining the three joint correspondences left 1,761 bony crossing pairs at the default pose, up from 719. Alternate-fits.json retains these failures.

## Replay and provenance

The standard Git binary delta clavicle-bones.patch restores the new NHBONES1 file from the parent SHA-256 in pins.json. It can be applied in a scratch directory containing the parent file. The matching NHTENDON3 is included. Run reproduce.sh on SSH Numi with the pinned inputs from the parent evidence. It rebuilds the geometry and tendon assets, checks each sampled bone pose, compares neighboring triangle identities, checks physical-layer coordinates and bed clearance, then launches the full native executable. The release gate remains open for capsular force routing, geometric inertia sensitivity, whole-body tissue clearance and supported native motion. Native-launch.json contains the compiler and linker commands, binary hashes and launch configuration. The donor assembly is mixed. The fitted articular boundaries are inferred.
