This is source and mass-import evidence for the repaired reference. It has no
physical step, contact simulation or motion qualification.

743,713 fat cells. The default capacity rejected this valid node count. The

volumes used by the closure recipe. Set `NUMI_HUMAN_NATIVE_ROLE_FLOW_OUTPUT`
to an existing empty directory to emit and reimport the two roles. Read an

receipt SHA variables shown in the harness.
