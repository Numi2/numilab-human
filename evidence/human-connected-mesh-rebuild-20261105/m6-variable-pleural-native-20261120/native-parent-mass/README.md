# Mass transfer from the native skin and fat parent

An earlier paired donor reconstruction differed by 4.901 g from the
exact parent in the scene. The runtime replacement correctly rejected
it. Recapture reproduced the archived native parent's five files
byte for byte. Source tetrahedron indices, material/region labels and
stable IDs were preserved. The P1 tuple preferences retain historical
distances. Retained maps were checked against the 20 mm source
projection bound with the captured parent displacement, and all
active carrier routes were rechecked in the current geometry.

The constrained correction uses the existing compensated feasible-flow
solver to discharge overfull receiver groups and then fill remaining
density minima. Reallocation preserves each carrier quota, keeps the
original material/donor/region support, and allows only edges within
the existing distance limit. The total transfer is 13.939678963460478 kg
across 5,910,094 expanded routes with zero density violations. The
production writer and both importer readers validated the exact role
files. The native role binding verifies the two solver-free reports
without weakening the source-ownership or allocation checks.

The scripts run in the retained SSH Numi evidence workspace and require
its prior pinned source assets. This evidence establishes static mass
replay. Native motion, equilibrium and throughput require separate
whole-scene evidence.
