## Source-backed posterior shoulder registration

Skin node 24331 carried 66.98% of the terminal bed impulse. The first scapular surface was 29.595 mm inside the registered skin. Direct comparison against all 13,118 corresponding vertices registered the source scapula to the accepted native frame with maximum error 0.061 µm. The source query screened 2,234 atlas members and tested 13 possible intersections.

The unmodified atlas places the ascending trapezius between 10.86 and 20.49 mm along the measured load normal. The infraspinatus occupies the final 3.88 mm before the scapula. In the running model the trapezius begins behind the first cortical surface and the infraspinatus covers about 0.025 mm before it. This comparison uses the measured scapula frame. The other muscles have their own anatomical motion and registration.

Two reversible trials use the existing NHTISS4 format. Replacing only the scapular donor introduced folds. Transforming the complete donor set in the same source chart placed the ascending trapezius between 10.78 and 20.47 mm, with zero ascending-trapezius self-intersections in the three posed checks. Its minimum bed clearance became -1.890 mm. It also increased overlap with the existing three-dimensional skin and fat. Both trials were rejected. The current coupled mechanics, repaired back and accepted skin/fat asset keep their existing owners.

For the next physical revision, the posterior muscle surfaces, local skin/fat boundaries and supported posture must be fitted together against the scapula and bed. Retain source mass, muscle and tendon attachments, the actual bed normal and measured force balance. A normal-line measurement does not determine three-dimensional force transmission.
