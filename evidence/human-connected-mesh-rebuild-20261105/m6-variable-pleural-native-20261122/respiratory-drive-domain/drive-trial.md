# Supported native respiratory response test

This 60 s sensitivity test uses the existing 60 s gluteal-registration scene and its original executable. Its 32 skin/fat bed sections have measured physical reactions. The dense tissue scene is a separate qualification. The control is the retained cold 30,000-step run at fe98cb96 with varying pleural pressure. The only physics input change is the existing respiratory drive multiplier 0.6 during [15,35) seconds. The multiplier returns to 1 for the remaining 25 s. Keep the same 2 ms timestep, scene, starting state, CPU scheduler, native presentation settings, controller and circulation. Pre-intervention numeric trace samples must agree exactly.

Measure inspired volume as the increase in the native cumulative inspired-volume column over [15,35] compared with the control; linearly interpolate only interval endpoints between observed samples. Require a reduction greater than 5% for a detectable ventilation response. Report diaphragm excursion, positive inspiratory airflow and pleural excursion. At 30–35 s expect higher arterial CO₂ and lower arterial O₂ relative to the matched control. At 55–60 s report how much each mean difference receded from the intervention-end difference; halving both is the predeclared recovery test. This is an engineering threshold for this window, not a biological time constant. Count breaths and ejection cycles, bed reactions, nonfinite values and O₂, CO₂ and blood-volume accounting over the actual accepted trial. Keep delayed changes and failed predictions.

The signs follow alveolar ventilation and gas mass balance. See [Merck Manual, Measurement of Gas Exchange](https://www.merckmanuals.com/professional/pulmonary-disorders/tests-of-pulmonary-function-pft/measurement-of-gas-exchange) and [OpenStax, Gas Exchange](https://openstax.org/books/anatomy-and-physiology/pages/22-4-gas-exchange). Neither the short window nor this reduced bed model qualifies the requested full anatomic 330 s baseline and intervention.
