# Preserve native query frames and accelerate exact parent registration

The source-bank audit now uses the inverse of each current emitted native Float32 local-to-world matrix in Float64. It retains the exact source-bank local triangles and COM offsets. Quaternion reconstruction, normalization, and treating a near-orthogonal Float32 matrix transpose as its inverse change the queried geometry. The old audit remains preserved. Six frame tests pass, including all 157 native body frames with inverse round-trip error at most 2.23e-16. This is a frame consistency check; the complete new surface/bone audit has not run yet.

The registered surface producer previously evaluated a rational point-to-AABB distance for every same-material parent tet whenever an ambiguous projection triggered its exact fallback. It now first computes conservative binary64 lower bounds using one downward nextafter per subtraction, product and addition, and an upward-rounded exact seed upper bound. Excluded AABBs cannot improve the seed. Surviving AABBs and every competing simplex projection retain exact rational evaluation, deterministic tie choice and rejection of equal-distance distinct projections. No nearest-K shortcut, geometry change or mass assumption is added.

Six numerical tests cover scale, boundary ulps, overflow, subnormal arithmetic, invalid bounds, exact ties and complete projection parity. Existing source/registration tests 230 and exact projection/frame tests 318 pass unchanged. Six matched queries on captured parent330 return identical tet row, rational projection, barycentrics, squared distance and ties. Each material has 14,316 parent tets; the old fallback took 90-103 ms/query and the filtered fallback 2.05-5.11 ms/query in this short sample. This measures the exact fallback, not complete export, simulation speed or end-to-end performance. Full export, volume meshing, conservative child mass transfer and motion remain pending.

The numerical helper and producer update are production tools. The evidence audit still has SSH Numi checkpoint paths and is an offline source-owner diagnostic. Existing artifact formats, source identities and passive anatomy declarations remain intact. Reference anatomy is mixed-source; no measured-person or clinical claim is made.
