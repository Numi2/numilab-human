# Typed skin/fat PLC preparation

The existing volume producer now consumes the pinned typed O/I/D candidate format. Source namespace and face IDs stay explicit. The donor head annuli are checked against their original parent packet, transformed only by an explicitly supplied existing native-placement packet, and reindexed onto the repaired domains. Float32 collapsed and zero-area facets are rejected. No boundary points are fitted.

Three focused programs pass on SSH Numi. The actual frozen O286 test finds all 45 O/I/D boundary nodes exactly after the recorded placement; both annuli preserve their positioned Float32 geometry and parent ancestry. The initial missing-placement failure is retained.

This change prepares source PLCs only. It does not create the repaired child volume, map its mass, install it, or verify physical motion.
