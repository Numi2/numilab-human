# Rejected passive forearm bone-support field

Candidate270 is an inferred passive attachment field built over the retained candidate200 source geometry. It blends toward ulna/radius support along registered forearm route landmarks and back to the original full-parent field near the carpal wrap. It is not a measured attachment map and does not modify active MyoSim routes. All work ran on SSH numi; geometry was CPU-replayed through pinned accepted body poses, not generated by a native candidate run.

At step0, both row self tests and the joined exterior pass. At step8000, each row still has zero self pairs, but their joined exterior has six exact segment crossings. Those span 2.3–78.1 micrometres between original source faces without shared vertex IDs. They are not generated seam contacts and remain disqualifying.

A separately requested diagnostic PQ census, run despite that rejection, gives 1,064 canonical parent pairs versus 1,177 in the retained baseline, with 387 added and 500 removed. Reduced aggregate count does not establish clearance. Raw joined PQ pairs are 1,509; raw and canonical counts must not be interchanged. No candidate270 asset was installed or run in the native scene.

Read-only wrist reconstruction from accepted poses gives maximum sampled wrist angles under 2.5 degrees in the retained 16-second and one-minute runs. The script verifies step0 against the source default q and pins the joint frames and poses. These observations do not isolate causes of tissue crossing or justify locking the wrist. No wrist constraint was changed.

The left forearm/PQ clearance remains unresolved. Scripts, field arrays, exact predicate dependencies and input identities remain at the paths pinned by the reports; the large assets were not duplicated into Git.
