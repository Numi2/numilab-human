# Human zero-crossing skin/fat surface preparation — 038

This evidence increment preserves the strongest frozen source/typed O/I/D surface bundle assembled from warning repair runs 004 and 005. It is a source-preparation checkpoint, not a completed physical transfer.

## Geometry and ancestry result

- The merged O proposal uses 202 selected O patch operations: 190 from run 004 and 12 from run 005. The other 8 run-004 operations are excluded because their retired face sets overlap. Original run operation JSONs and correction receipts are retained.
- Typed surfaces load through the existing 217 O/I/D owner: O 76,669 points / 153,293 faces; I 125,368 / 250,731; D 120,628 / 242,135. Each role retains its 45-edge boundary.
- The independent fixed-coordinate delta check reports zero changed-face intersections against the selected complete-current surface records, zero changed-face intersections against all 185 bones in both coordinate domains, and all 149 protected targets verified.
- The delta verifier selected 7,614 changed faces against 646,159 complete-surface records and marks `complete_surface_audit=false`; it reuses the pinned baseline proofs in this directory. This is not a fresh full all-to-all current-surface scan.
- D source coordinates were restored from the original F64 proposal to the source F32 dtype through the included non-mutating restoration path and receipt. The restoration does not claim any geometry improvement.

## Qualification boundary

This package does **not** establish positive F32 tetrahedral volume quality, mass mapping/conservation, native runtime admission, or physical/physiological qualification. Parent staging notes report a separate current fat TetGen output of 853,727 tets with 16 F32 collapsed/zero tets; that status is included as context only and is not independently verified by this package. No TetGen body mesh is included here.
