# Quality volume archive chunk 001

This publication preserves the backup and cleanup proof for 12 pre-824 historical quality volume proposal arrays. The archive itself remains a GitHub release asset and is not copied into this repository.

Read RESTORE.md for the exact asset filename, release tag, digest, and restore command. The plan directory copies the complete retained text/source package from the Numi run. It includes build, independent GitHub verification, CRC/header readback, one-member restore, retirement, protected-input proof, temporary-copy cleanup, and lane-release receipts.

The build receipt records the earlier pre-upload stage, where remote verification and retirement had not yet occurred. Later verification and cleanup receipts document the subsequent passing steps; all versions are retained.

A current-state reference in the post-retirement proof is an input-protection pin only. This package is not a geometry or physical/native qualification record. No NPZ or NPY arrays are bundled.
